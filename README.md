# Jellypod Skills

Skills for AI assistants to use Jellypod.

## Available Skills

| Skill | Description |
|-------|-------------|
| **[platform-api](./platform-api/)** | Use the Jellypod API to create AI-powered podcasts — hosts, sources, episodes, and publishing |

## What are Skills?

Skills are structured instructions that teach AI coding assistants (like Claude Code, Cursor, Windsurf, etc.) how to use a tool or API. They provide the context an agent needs to write correct integration code without hallucinating endpoints or parameters.

## Installation

### Claude Code

```bash
npx skills add jellypod/skills
```

### Manual

Copy the relevant `SKILL.md` file into your project or AI assistant's context.
